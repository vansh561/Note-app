# BlueNote frontend (React + Vite)

1. Start your backend:  `npm run server`   (runs on http://localhost:8080)
2. In this folder:      `npm install && npm run dev`
3. Open http://localhost:5173

Requests to `/api/*` are proxied to your Express server (see vite.config.js),
so no CORS changes are needed. If your PORT is not 8080, edit vite.config.js.
